# 2-Look OLL & PLL Reference

A single-page printable cheat sheet for the 2-look OLL and PLL stages of CFOP, with each algorithm broken down into named triggers (sexy move, sledgehammer, fruruf, sune, etc.) and color-coded so the patterns are easy to see.

Click a case to highlight the one you're currently practicing — your selection persists across reloads.

Cube diagrams rendered by [VisualCube](https://visualcube.api.cubing.net/), bundled locally; Ua/Ub overlays drawn as SVG so the directional arrows are clearly visible.
